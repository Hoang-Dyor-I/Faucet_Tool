## 2024-05-24 - Credential Exposure and Local IP Leak in Proxy Implementation
**Vulnerability:** Proxy strings containing plain-text credentials (user:password) were exposed in script logs. Additionally, malformed proxies could result in local IP leakage due to insecure proxy parsing fallback, and raw exception tracebacks were printed.
**Learning:** Logging directly from a configuration source without filtering can result in PII/credential leaks. Unhandled edge cases in proxy parsing that proceed to make requests can reveal the host machine's IP, bypassing intended operational security. Furthermore, exception traces printed in production logs can expose internal implementation details.
**Prevention:** Implement rigorous credential masking (`mask_proxy`) before any configuration is logged. Validate and parse connection setups securely, aborting operations explicitly when expected proxy structures fail (`if proxy is None: return`), rather than falling back to defaults. Mask full exception objects in logs, emitting only their class/type (`type(e).__name__`) and safe context.
