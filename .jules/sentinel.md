## 2024-11-01 - Prevent Credentials Leakage in Sol Devnet Script
**Vulnerability:** The script `Sol/Sol_Devnet.py` was printing raw proxy strings and unhandled exception details (`str(e)`) to the console, exposing sensitive proxy credentials (username/password) in plaintext. It also failed to percent-encode passwords containing special characters (like `@` or `:`), which could lead to malformed URLs and authentication bypass or failure.
**Learning:** Hardcoded credentials and unhandled exception messages are common vectors for sensitive data leakage. Additionally, URLs constructed using string formatting without proper URL encoding can introduce vulnerabilities or functional bugs when credentials contain special characters. Furthermore, when dealing with threaded batch operations, proxy handling needs to be robust against malformed input strings to avoid crashing.
**Prevention:** Always sanitize/mask sensitive strings before logging (e.g., using regex to redact passwords from proxy URLs). Always URL-encode credentials (using `urllib.parse.quote`) before embedding them in URLs. Ensure defensive programming by validating input formats before processing them in automated scripts.
