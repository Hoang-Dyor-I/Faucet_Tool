## 2024-05-24 - Credential Leakage in Proxy Logs and Exceptions
**Vulnerability:** Proxy passwords were being leaked in plaintext to stdout when logging the current proxy in use. Additionally, unhandled exception messages from `requests` leaked the proxy credentials embedded in the connection URL. Credentials containing special characters also lacked percent-encoding, leading to authentication bypass or injection issues.
**Learning:** Raw proxy strings (`host:port:user:pass`) cannot be safely printed. Furthermore, underlying libraries like `requests` embed authentication in exception messages when a proxy connection fails, unintentionally leaking secrets.
**Prevention:** Always parse proxy strings and mask the password before logging. Use regex to sanitize exception messages that might contain URLs with credentials. Always URL-encode credentials when constructing proxy auth URLs.
