## 2024-06-08 - Proxy Credential Exposure in Console Logs
**Vulnerability:** Proxy credentials (passwords) were being printed directly to stdout via `print(f"\n🌐 Đang dùng proxy: {proxy}")` and potentially leaked through unhandled exceptions via `print(f"⚠️ Lỗi proxy hoặc kết nối cho {wallet} - {e}")`. Additionally, credentials containing special characters weren't URL-encoded.
**Learning:** Raw string formatting of proxy configurations containing credentials directly into logs or exception traces poses a critical security risk (credential exposure). Similarly, using string `split(":")` without a maxsplit limit can incorrectly truncate passwords that contain colons.
**Prevention:** Always mask credentials before logging using secure formatting (e.g., `mask_proxy()`). Handle exception traces containing URLs by applying regex sanitization (`re.sub(r'(://[^:]+:)[^@]+(@)', r'\1***\2', str(e))`). Ensure network credentials are properly percent-encoded (`urllib.parse.quote()`) to avoid malformed URLs and parse securely with `split(":", 3)`.
