## 2024-07-20 - Prevent Credential Leakage in Proxy Errors and Terminal Output
**Vulnerability:** The script was logging raw `Exception` objects from the `requests` library when proxy connections failed, which leaks plaintext credentials embedded in the proxy URLs. It also printed out proxies with plaintext passwords to the console when starting batches. Furthermore, proxy credentials were not properly percent-encoded, which can cause injection-like issues.
**Learning:** Python exception strings often include raw configuration details (like proxy URLs in `requests`). Masking or sanitizing exception logs is critical to avoid leaking credentials. Also, `requests` library percent-encodes credentials in error outputs, meaning regex matchers used to mask strings must handle url-encoded characters.
**Prevention:** Always mask credentials (e.g., using `re.sub`) before logging network exception strings and implement a utility to redact passwords from terminal logs. Always url-encode proxy credentials.
