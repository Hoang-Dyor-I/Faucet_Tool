## 2024-08-17 - Prevent Proxy Credential Leakage in Solana Airdrop Script
**Vulnerability:** Proxy passwords were leaked in plaintext directly to the console during normal execution and potentially via exception messages containing the raw URL. Additionally, credentials were not URL-encoded causing parsing vulnerabilities for passwords containing special characters like colons (`:`).
**Learning:** Hardcoded `.split(":")` breaks when passwords contain colons. Python's `requests` exceptions stringify the full proxy URL which leaks encoded secrets (`%40` instead of `@`) if not explicitly sanitized via Regex. Global scope file I/O operations create destructive side effects when the file is imported.
**Prevention:** Always use `maxsplit` (e.g. `split(":", 3)`) when parsing credentials. Apply strict regex-based sanitization over exception messages (`re.sub(r'(://[^:@/]+:)[^:@/]+(@)', r'\1***\2', str(e))`) before logging. Encapsulate file reading operations inside an `if __name__ == '__main__'` or `main()` block and enforce URL-encoding (`urllib.parse.quote`) on all injected credential strings.
