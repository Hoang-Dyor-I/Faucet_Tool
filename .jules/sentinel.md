## 2024-05-24 - Prevented proxy credentials leakage and injection
**Vulnerability:** Proxy credentials (user and password) containing special characters like `@` or `:` were not URL encoded, leading to malformed URLs and possible injection. In addition, when network connection failed, `requests` library exception outputs would leak plaintext URLs containing user credentials, which could be logged or printed to standard output.
**Learning:** `requests` proxies are instantiated from URLs where credentials need to be appropriately percent-encoded to prevent structural parsing breaks. Exception tracebacks and object string representations often embed these same unmasked URLs.
**Prevention:** Always percent-encode proxy credential components using `urllib.parse.quote` before interpolating them into HTTP proxy URL strings. Sanitization routines (like regex `re.sub`) should be employed specifically to intercept and mask sensitive portions of proxy URLs (`***`) inside exception handlers before outputting or logging them.
