## 2024-11-07 - Proxy Credentials Leakage via Requests Exception
**Vulnerability:** Proxy credentials (passwords/usernames) with special characters were not URL-encoded leading to malformed proxy strings, and raw exceptions from `requests` leaked percent-encoded proxy credentials when printing to logs.
**Learning:** The `requests` library automatically percent-encodes credentials in its error output. When masking passwords in exceptions using regex, the regex needs to handle the percent-encoded version (e.g., `%40` instead of `@`) or mask the generic authentication block structure `://[^:]+:***@`. Furthermore, special characters in proxy credentials must be pre-encoded with `urllib.parse.quote` for URL construction.
**Prevention:** Always URL-encode user-supplied credentials before passing them into proxy dicts. Sanitize exception strings via regex matching the URL auth format before logging, rather than relying on exact plain-text password matching, as libraries may manipulate the string format internally.
